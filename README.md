# Prestige City Goa – Project Resources

**Prestige City Goa** is a 110-acre mixed-use integrated lifestyle destination in **Sancoale, South Central Goa**, near **Dabolim International Airport**.

The project offers:
- **311 Luxury Plots**
- **90+ Luxury Villas**
- **300+ Luxury Apartments (G+12)**
- On-site **Luxury Resort**
- **Shopping Mall & Retail Space**
- Spanish-inspired architecture with cliff-top Arabian Sea views
